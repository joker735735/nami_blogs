## 概要（何をやったか / 学んだこと）
- Java scriptの世界
- データを表示しろという命令
<br>
console.log()
を書くことで、「表示しろ」という命令になる。かっこの中は（""）のように、ダブルクォーテーションで囲む。
<br>
console.logを関数、かっこの中を引数と言う。
- メモの書き方
<br>
コードの頭に//を付けるとそのあとの文字列はメモ扱いになる表示されない。
- 計算の仕方
<br>
かっこの中のダブルクォーテーションを外すと文字列扱いから数値扱いになる。

## つまずいたところ & 解決策
### エラーや疑問
```bash
# コード末に;を付け忘れ
```

### 原因・対処
- ;がなくても実行できてしまうので；を付けずに実行しがちだった。癖付けるために丁寧に数を重ねる事が大切かも。

## 参考リンク / ひとことメモ
- メモは//でもできるが、頭と最後を/**/で囲むことで数列にわたってメモにすることもできる。
- かっこの中の計算式は足し算が+、引き算が-、掛け算が*、割り算が/で表す。
