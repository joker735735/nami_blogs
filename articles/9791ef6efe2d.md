### エラーや疑問

```bash
1.  fatal: not a git repository (or any of the parent directories): .git
```





### 原因・対処
:::
**💡 学び・原因**
1.編集しようとしているファイルが存在していない。
gitに存在しているファイルに移動する必要がある。
コマンドは
```bash
cd (ファイル名)
```
