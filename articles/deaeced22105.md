## 概要（何をやったか / 学んだこと）
- ブランチについて理解を深めイメージをリアルにする。

ブランチとはバージョン管理システムで使用されるプログラミング用語である。
<br>コピーしたデータを作成し（ブランチを作成）そこで編集を進めることでメインデータに影響を与えず編集をすることができる。
<br>最終的に統合（merge）することができる。この枝分かれした作業場をブランチという。

- ブランチを作成するコマンド
```
git checkout -b feature/チケットの数字　origin/main
```


## つまずいたところ & 解決策
### エラーや疑問
```
mainにそのまま直接pushしてしまった
　
```

### 原因・対処
:::message
**💡 学び・原因**

- mainに直接送り込むのは絶対だめ！！
<br>チェックも終わっていないのにいきなりリリースしてしまうことになるよ！絶対危険だから注意するように！


## 参考リンク / ひとことメモ
- ブランチで編集したものはmainではなくブランチのほうにpushすること
<br>この時点ではmainに影響はない。

- 編集が終わったらpullリクエストで確認を取ってもらう。
- 合格が出たら完了。mergeしてリリースできる！！
